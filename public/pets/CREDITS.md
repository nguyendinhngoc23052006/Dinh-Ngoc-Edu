# Pet sprite credits

The pet companion sprites in this folder are from the **Ninja Adventure Asset Pack**
by Pixel-boy / Sparklin Labs, released under **CC0 1.0 (public domain)**.

- Source: https://github.com/sparklinlabs/superpowers-asset-packs (`ninja-adventure/monsters`)
- License: CC0 1.0 Universal — no attribution required, but appreciated.

Each file is a 64×64 spritesheet: 4 walk frames across × 4 direction rows of 16×16.
Files are named by `species.id` so the renderer can resolve `/pets/<species_id>.png`
by convention; a missing or failed image falls back to the species emoji.
